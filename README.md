# Rainfall Analysis and Planting Advisory

- This project analyses monthly rainfall data from five Kenyan counties using Python and NumPy to identify rainfall patterns and suitable planting windows.
- To run the analysis, open `rainfall_analysis.ipynb` in Google Colab, ensure NumPy is available, and run all cells from top to bottom.
- The rainfall-based planting advisory recommends April–May for Nairobi, Nakuru, Kisumu and Mombasa, and November–December for Machakos.

## Project Files

- `rainfall_analysis.ipynb`: Complete rainfall cleaning and analysis.
- `rainfall_summary.csv`: Summary of rainfall statistics and planting windows.
- `requirements.txt`: Required Python library dependencies.
